# diff 방식 비교 결과

- 측정 시각: 2026-10-16 00:28
- 환경: Ubuntu 24.04.5 LTS, X64, 논리 CPU 4, .NET 8.0.32, git version 2.43.0
- 방법: 경우마다 두 파일을 디스크에 써 두고, 방식마다 첫 실행(JIT·결과 검증) 뒤 최대 5회(3초 넘으면 중단) 측정한 **중앙값**. 파일 읽기 포함.
- 변경 줄 = 삭제 줄 + 추가 줄(작을수록 최소 diff에 가까움). ✓ = 결과로 옛 파일을 새 파일로 정확히 재구성됨을 확인.
- 메모리 = 1회 실행의 관리 힙 할당량. git CLI는 별도 프로세스라, LibGit2Sharp는 네이티브 메모리라 대부분 잡히지 않는다.
