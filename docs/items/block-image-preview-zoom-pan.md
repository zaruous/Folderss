# 블록 이미지 팝업 확대와 이동

- 상태: Done

## 요구사항
- 블록 편집기 이미지 팝업에서 Ctrl+마우스 휠로 이미지를 확대·축소한다.
- 마우스 가운데 버튼을 누른 채 끌어 확대된 이미지를 이동한다.
- 이미지 보기 영역에서 마우스 왼쪽 버튼을 누른 채 끌어도 확대된 이미지를 이동한다.
- 기존 창 맞춤, 스크롤바, Esc 닫기 동작을 유지한다.

## 원인 분석 또는 설계
- `BlockImagePreviewWindow`는 `Image`를 `ScrollViewer`에 직접 넣고 `Stretch`만 전환하므로 배율과 포인터 기준 스크롤을 관리하지 않는다.
- 팝업 전용 배율과 이미지 크기를 관리하고, 확대 전 포인터가 가리킨 이미지 위치가 확대 후에도 같은 화면 위치에 오도록 스크롤 오프셋을 조정한다.
- 이미지 보기 영역에서 왼쪽 또는 가운데 버튼을 누른 채 드래그하면 스크롤바 오프셋을 시작 위치에서 이동량만큼 갱신한다. 스크롤바 위의 왼쪽 클릭은 스크롤바가 처리한다.

## 구현 내용
- 팝업 이미지에 10~800% 배율을 적용하고 현재 배율을 상단에 표시한다.
- Ctrl+휠의 한 단계마다 1.2배 확대·축소하며 휠 포인터가 가리킨 이미지 위치를 기준으로 스크롤 오프셋을 조정한다.
- 이미지 보기 영역에서 왼쪽 또는 가운데 버튼을 누른 채 끌면 가로·세로 스크롤 오프셋이 이동한다. 스크롤바는 왼쪽 클릭을 그대로 처리하고, 마우스 캡처 해제 시 드래그 상태를 정리한다.
- 창 맞춤을 켜면 창 크기에 맞춰 축소하고 창 크기 변화에 맞춰 다시 계산한다. 수동 확대 시 창 맞춤을 해제한다.
- 배율 표시의 툴팁과 README에 조작법을 추가했다.
