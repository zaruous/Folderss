# 마크다운 제목 4~6단계(`####`~`######`) 표시

- 상태: Ready for Verification

## 요구사항

`#### 제목`이 제목 서식으로 보이지 않는다. 블록 편집기와 마크다운 뷰어 둘 다, 4~6단계 모두 지원한다(사용자 선택).

## 원인

- 블록 편집기: `BlockMarkdown.ParseCore`가 `#` 4개 이상을 문단으로 바꿨다(`BlockKind`에 제목 1~3만 있음). `#### ` 기호가 보이는 일반 문단이 됨.
  기존 테스트 `UnknownConstructs_ArePreservedAsTextOrRaw`가 이 동작을 의도로 고정하고 있었다.
- 마크다운 뷰어: `<h4>`~`<h6>`는 만들어지지만 `markdown-app.html` CSS에 h1~h3 크기만 있어 본문 크기 굵은 글씨로 보였다.

## 구현

- `BlockKind.Heading4/5/6` — 기존 값 번호가 바뀌지 않게 enum 끝에 추가. `GetHeadingLevel` 4~6.
- `BlockMarkdown`: 읽기(`#`×1~6 → 제목 종류), 쓰기(`#`×단계), 입력 단축 `#### `~`###### `. setext(`===`/`---`)는 1·2단계만.
- 편집기 표시: 글자 크기 16.5/15/15(본문 15, 5·6단계는 굵기로 구분), 굵게, 자리표시 "제목 4~6", 높이 추정, `/h4`~`/h6` 명령, 빈 제목 처리(`IsHeading`).
- 클립보드 HTML 붙여넣기 `<h4>`~`<h6>` → `####`~`######`.
- 뷰어 CSS: h4 1.05em, h5 1em, h6 .9em(보조 색).
- 블록 전환 단축키(사용자 결정): `Ctrl+Alt+0` 텍스트, `1~6` 제목 1~6, `7` 할 일, `8` 글머리, `9` 번호.
  예전 `4` 할 일·`5` 글머리·`6` 번호·`7` 토글·`8` 코드에서 바뀜 — 토글·코드는 숫자 단축키가 없어지고 `/` 명령(코드는 입력 단축 ```` ``` ````도)으로만 바꾼다.
  `/` 메뉴의 토글 힌트 `Ctrl+Alt+7` 제거.
- 하지 않은 것: 토글 제목은 1~3 유지.

## 위험·주의

- 기존 문서의 `#### …` 줄이 이제 제목 블록이 된다. 편집하지 않으면 원문 그대로 저장(최소 변경 저장). 그 줄을 편집하면 정규형(`#### 글`, 닫는 `#` 제거)으로 저장된다.
- 기존 단축키를 외운 사용자는 `Ctrl+Alt+4~8`을 누르면 다른 블록이 된다(실행 취소로 되돌릴 수 있음).
- 문서 목차(`[TOC]`)·찾기·뷰 전환 앵커에 4~6단계 제목이 새로 포함된다.

## 검증

- `dotnet test tests/Folderss.SearchTests` (Linux): 1140 통과 / 5 건너뜀. 새 테스트: 제목 4~6 읽기·왕복, `#######`는 문단, 입력 단축 4~6,
  무편집 바이트 동일(닫는 `#`·공백 포함), 제목 4 한 줄 편집 시 그 줄만 바뀜.
- 앱 빌드(Linux): 기존 Windows 전용 `Microsoft.Terminal` 참조 오류 1건 외 오류 없음.

- 확인하지 못한 것: Windows에서 편집기·뷰어 화면 모양(글자 크기·테마), 목차 들여쓰기.
