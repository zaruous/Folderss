# 블록 편집기 1단계: 표 조작 (#75 "표")

- 사용자 확인: 대기

## 요구사항

이슈 #75(블록 편집기 1단계: 편집 조작) 중 "표" 항목. 같은 이슈의 "선택·이동", "찾기·외부 변경·링크"는 다른 작업(별도 브랜치)에서 한다.

- 셀 오른쪽 클릭 메뉴: 위·아래 행 삽입, 왼쪽·오른쪽 열 삽입, 행 삭제, 열 삭제, 열 정렬(왼쪽·가운데·오른쪽). 각각 실행 취소 한 단계
- 열 너비 조절(경계 드래그) — #78 결정대로 사이드카
- 행·열 끌어 옮기기
- 머리글 행 켜기·끄기 — Markdown 표는 머리글이 필수이므로 표시만 바꾸고 사이드카에 저장

원칙: 가상화(보이는 블록만 행 생성), 편집하는 행에만 TextBox(입력기 TSF 잠금 회피), 실행 취소는 변경 구간만 기록, 1만 줄 문서 성능(표 행 추가 중앙 ≤ 70ms, 글자 입력 ≤ 20ms).

## 설계

표는 같은 들여쓰기로 이어진 `TableRow` 블록 [start, end)이고, **표 전체 속성은 표의 첫 행(Markdown 머리글) 블록에 둔다** — 기존 열 정렬 `TableAlign`과 같은 자리.

| 속성 | 저장 | 값 |
|---|---|---|
| 열 정렬 `TableAlign` | Markdown 구분 행(`:---`·`:---:`·`---:`) | 열마다 `l`·`c`·`r`·빈 값, 쉼표 구분 |
| 열 너비 `colwidths` (`EditorBlock.AttrColWidths`) | 사이드카 | 열마다 px 정수, 빈 값은 자동(남은 폭을 나눔). 예: `120,,200`. 모두 자동이면 속성 삭제 |
| 머리글 끄기 `noheader` (`EditorBlock.AttrNoHeader`) | 사이드카 | `true`. Markdown에는 첫 행이 그대로 머리글로 저장되고 화면에서만 일반 행처럼 그린다 |

- 키 이름은 기존 사이드카 키(`colratio` 등)처럼 소문자 한 단어.
- 첫 행이 바뀌는 연산(첫 행 위에 행 삽입, 첫 행 삭제 — `Backspace` 빈 행 삭제 포함, 행을 끌어 첫 행과 자리 바꿈)은 `BlockTable.TransferHeader`로
  정렬·`colwidths`·`noheader`를 새 첫 행으로 옮긴다. 행 자체 속성(`color`·`background`·`column`)은 행을 따라간다.
- 열 삽입·삭제·이동은 셀·정렬·너비를 같은 자리로 함께 옮긴다.
- 순수 로직은 `Services/BlockTable.cs`(WPF 없음, 테스트 프로젝트에 소스 링크). 편집기 연결은 `Controls/BlockEditor.TableOps.cs`(메뉴·끌기·연산),
  행 화면은 `BlockEditor.Row.cs` 표 절(열 너비 적용, 셀 손잡이), `BlockEditor.Table.cs`의 기존 열 추가·삭제·빈 행 삭제가 `BlockTable`을 쓰도록 바꿈.
- 연산은 블록 목록을 바꾼 뒤 `SyncRows` → `RecordChange` 한 번 — 실행 취소 한 단계, 기록은 바뀐 구간(그 표)만.
- 열 너비 끌기: 끄는 동안은 첫 행 속성만 바꾸고 화면에 만들어진 그 표의 행에만 `ApplyRowContext`를 다시 부른다(문서 전체 구조 재계산 없음). 놓을 때 기록 한 번.
- 셀 손잡이(오른쪽 경계 = 너비, 위쪽 가운데 = 열 옮기기, 첫 셀 왼쪽 = 행 옮기기)는 그 셀에 마우스를 처음 올릴 때 만든다 — 행 추가 비용에 들어가지 않는다.
  경계 두 번 클릭은 그 열 너비를 자동으로.
- 셀 메뉴는 셀 칸의 `PreviewMouseRightButtonUp`에서 띄워 TextBox 기본 메뉴(잘라내기 등)를 대신한다. 메뉴 스타일은 `Controls.xaml` 공통 템플릿.

- WPF 하네스(스크래치, 저장소 밖) 추가 검사 항목 — 병합 후 일괄 실행:
  1. 셀 오른쪽 클릭 → 메뉴(위·아래 행 삽입, 왼쪽·오른쪽 열 삽입, 행·열 삭제, 열 정렬 ▸ 왼쪽·가운데·오른쪽, 머리글 행 체크, 너비를 정한 표면 "열 너비 모두 자동"), TextBox 기본 메뉴는 안 뜸
  2. 위에 행 삽입(머리글 위 → 새 행이 머리글, 정렬 유지) / 아래에 행 삽입 / 각 Undo 한 번에 원상태
  3. 왼쪽·오른쪽 열 삽입 → 커서가 새 열, Markdown 구분 행 열 수 / Undo
  4. 행 삭제(머리글 행 삭제 → 다음 행이 머리글, 정렬 유지) / 열 삭제(열 1개면 비활성) / Undo
  5. 열 정렬 가운데·오른쪽 → 셀 TextAlignment, 저장 Markdown `:---:`·`---:` / Undo
  6. 열 경계 끌기 → 같은 표의 화면 행 모두 같은 열 폭, 저장 사이드카 `colwidths`, 다시 열기 후 유지, 경계 두 번 클릭 자동 / Undo 한 단계
  7. 열 손잡이 끌기 → 셀·정렬·너비 함께 이동 / 행 손잡이 끌기 → 행 순서, 첫 행 이동 때 머리글 속성 유지 / 캡처 잃으면 취소
  8. 머리글 행 끄기 → 첫 행 굵게·배경 해제(위 테두리 유지), Markdown 불변, 사이드카 `noheader`, 다시 열기 후 유지 / Undo
  9. 성능: 1만 줄 문서 표 Enter 행 추가 중앙 ≤ 70ms, 셀 글자 입력 ≤ 20ms(셀 손잡이는 지연 생성이라 변화 없어야 함)
- 빌드: `dotnet build .\Folderss.sln -c Debug`, `dotnet build tests/Folderss.SearchTests` 성공.

## 남은 일·주의

- 블록 손잡이(⋮⋮)로 표의 첫 행을 표 밖으로 끌어내면 정렬·`colwidths`·`noheader`가 그 행을 따라간다(블록 끌기는 "선택·이동" 작업 범위라 손대지 않음).
- 열 너비는 px 고정이라 편집기 폭이 좁으면 표가 잘릴 수 있다(가로 스크롤 없음). 자동 열이 남은 폭을 나눈다.
